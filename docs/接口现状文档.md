## 一、服务概览

| 项 | 值 |
|----|-----|
| 框架 | FastAPI + Uvicorn |
| 入口 | `python -m service.main`（监听 `:8800`） |
| 接口前缀 | `/api/v1` |
| 风格 | **REST**（资源名词复数 + HTTP 方法表动作 + 嵌套子资源） |
| 数据层 | `mastery_store`（PostgreSQL）+ 题库 JSONL + kg_graph 静态文件 |

启动顺序：`lifespan`（建 KPRegistry）→ TraceId 中间件 → 异常处理器 → 路由。

---

## 二、分层架构

- **api/**（路由层·薄）：参数校验 → 调 svc → 组装 `ApiResponse`
- **svc/**（业务层）：业务逻辑，错误时直接 `raise BizError`
- **core/**（基础设施）：response / config / deps / kp_registry / middleware / logging
- **mastery_store**（数据层）：掌握度模型 + practice_event 读写 + 常量

依赖方向：`api → svc → core → mastery_store → data/`，严禁反向。`api/` 不含业务逻辑，`svc/` 错误直接 `raise BizError`。

---

## 三、统一约定

### 3.1 响应封装
所有业务接口统一返回 `ApiResponse`：`{code, msg, data, trace_id}`，响应头带 `X-Trace-Id`。`code=0` 成功。例外：`GET /health` 裸返回 `{"status":"ok"}`。

### 3.2 错误处理
svc 层发现错误 → `raise BizError(code, msg, http_status, data)` → 全局 handler 转 ApiResponse。api 层不做错误翻译。三类异常都由全局 handler 收敛成同一 ApiResponse：① Pydantic 请求体校验失败（422）→ `RequestValidationError` handler（`code=40001`，`data.errors` 带字段级报错）；② 框架级 `HTTPException`（404 路由不存在 / 405 方法不允许等）→ 按状态码映射到 `NOT_FOUND`/`METHOD_NOT_ALLOWED` 等业务码；③ 未捕获异常 → 500 `INTERNAL`。三者都**不再**返回框架默认的 `{detail}`。四个 handler 共用 `_api_json`，保证结构完全一致。

### 3.3 REST 约定（核心）
- **资源用名词复数**：`students`、`practice-events`、`recommendations`
- **HTTP 方法表动作**：`GET`=读（幂等无副作用）、`POST`=创建/计算
- **路径表达层级**：`/students/{student_id}/mastery` = "该学生的掌握度"
- **参数位置**：
  - 路径参数 `{student_id}` 表资源标识
  - GET 的过滤条件走 **query**（`?kp_ids=J03&kp_ids=J04`）
  - POST 的数据走 **body**（student_id 在路径，不重复放 body）
- **状态码**：POST 创建资源返回 **201**（如 `/practice-events`），其余成功 200

### 3.4 KP 标识
API 边界一律用 `kp_id`（题库唯一 id）；内部 `kp_idx` 不外露；转换走 `KPRegistry`。全量查询只返回有题库映射的 idx。

### 3.5 时间
内部统一 naive UTC；submit-answer 的 `ts` 按 ISO 8601 解析，范围限制 now-30天~now+1分钟。

## 五、接口详解

> 所有响应统一走 `ApiResponse` 封装：`{code, msg, data, trace_id}`，成功 `code=0`。下方每个接口均给出**完整 JSON** 的请求体 / 成功响应 / 错误响应，字段与取值与代码逐一对应（示例中的 `kp_id`、`question_id` 仅为占位，以实际题库为准）。

### 5.1 GET /students/{id}/mastery — 遗忘后掌握度

**query**：`kp_ids`（可选，多次传即 `?kp_ids=J03&kp_ids=J04`，不传=该学生全部有映射的知识点）

**成功响应（200）**
```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "student_id": 1001,
    "now": "2026-07-21T08:30:00",
    "items": [
      {
        "kp_id": "J03",
        "kp_name": "一元二次方程",
        "m": 0.6234,
        "m_peak": 0.7100,
        "N": 12.5,
        "last_ts": "2026-07-15T10:00:00",
        "days_since": 5.21,
        "has_data": true
      },
      {
        "kp_id": "J04",
        "kp_name": "二次函数",
        "m": 0.5,
        "m_peak": 0.5,
        "N": 0.0,
        "last_ts": null,
        "days_since": 0.0,
        "has_data": false
      }
    ]
  },
  "trace_id": "a1b2c3"
}
```

**错误**：`KP_NOT_FOUND`（404）— 传入的 kp_id 不存在
```json
{ "code": 40403, "msg": "部分 kp_id 不存在", "data": { "invalid_kp_ids": ["J99"] }, "trace_id": "a1b2c3" }
```

**逻辑**：只读衰减（不落库），数学与 mastery_store 写路径逐行一致。`has_data=false` 表示无历史数据（冷启动 `m=0.5`）；`m`=当前衰减掌握度，`m_peak`=历史峰值，`N`=证据量，`days_since`=距上次作答天数。

### 5.2 POST /students/{id}/mastery — 初始化/重置掌握度（201）

**body**（三字段均可选，全空=冷启动）：
```json
{
  "correct_counts": { "J03": 8, "J04": 5 },
  "wrong_counts":   { "J03": 2, "J04": 3 },
  "last_ts":        { "J03": "2026-07-15T10:00:00Z", "J04": "2026-07-14T09:00:00Z" }
}
```

**成功响应（201）** — 回读返回，`data` 格式同 5.1
```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "student_id": 1001,
    "now": "2026-07-21T08:30:00",
    "items": [
      { "kp_id": "J03", "kp_name": "一元二次方程", "m": 0.8, "m_peak": 0.8, "N": 10.0, "last_ts": "2026-07-15T10:00:00", "days_since": 5.21, "has_data": true }
    ]
  },
  "trace_id": "a1b2c3"
}
```

**错误**：
- `KP_NOT_FOUND`（404）`{invalid_kp_ids:[...]}` — 同 5.1
- `422`（`code=40001`，`msg="请求参数校验失败"`）— count 为负，或 `last_ts` 非 ISO8601；`data.errors` 为 Pydantic 字段级报错列表（同样走统一 ApiResponse，见 3.2）

**逻辑**：kp_id 校验 → 组装 α/β/last_ts 向量（长度 N_KP，未提及填 0/None）→ `mastery_store.init_student`（UPSERT 覆盖）→ 回读。注入后 `m=(correct+P)/(correct+P+wrong+P)`。已有数据会被覆盖，故同时支持初始化与重置。

### 5.3 GET /students/{id}/practice-events — 做题序列

**query**：`kp_id`（必填）、`limit`（1..500，默认 50）、`wrong_only`（默认 false）

**成功响应（200）**
```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "student_id": 1001,
    "kp_id": "J03",
    "count": 2,
    "events": [
      {
        "question_id": "Q-2024-001",
        "ts": "2026-07-15T10:00:00",
        "ques_type": "选择题",
        "difficulty": "适中",
        "score": 1.0,
        "is_wrong": false,
        "kp_ids": ["J03", "J05"]
      },
      {
        "question_id": "Q-2024-008",
        "ts": "2026-07-14T16:00:00",
        "ques_type": "填空题",
        "difficulty": "较难",
        "score": 0.0,
        "is_wrong": true,
        "kp_ids": ["J03"]
      }
    ]
  },
  "trace_id": "a1b2c3"
}
```

**错误**：`KP_NOT_FOUND`（404）`{invalid_kp_ids:[kp_id]}`

**逻辑**：按时间倒序，kp_id 校验在 api 层。一题关联多 KP 时，`kp_ids` 返回该题的全部知识点。

### 5.4 POST /students/{id}/practice-events — 答题（201）

**body**（仅 `question_id` / `score` / `source` 必填，其余可选）：
```json
{
  "question_id": "Q-2024-001",
  "score": 0.0,
  "is_wrong": true,
  "source": "homework",
  "ts": "2026-07-21T08:30:00Z",
  "equal_weights": false,
  "client_request_id": "req-abc-123"
}
```

**成功响应（201）**
```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "student_id": 1001,
    "question_id": "Q-2024-001",
    "score": 0.0,
    "is_wrong": true,
    "question": { "ques_type": "选择题", "difficulty": "适中", "kp_ids": ["J03", "J05"] },
    "updated_kps": [
      {
        "kp_id": "J03",
        "kp_name": "一元二次方程",
        "m_before": 0.6234,
        "m_after": 0.5512,
        "delta": -0.0722,
        "level_before": "巩固",
        "level_after": "补弱"
      },
      {
        "kp_id": "J05",
        "kp_name": "配方法",
        "m_before": 0.71,
        "m_after": 0.66,
        "delta": -0.05,
        "level_before": "变式",
        "level_after": "巩固"
      }
    ]
  },
  "trace_id": "a1b2c3"
}
```

**幂等命中**（相同 `client_request_id` 已处理过，不重复更新掌握度）：
```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "student_id": 1001,
    "question_id": "Q-2024-001",
    "idempotent_replay": true,
    "message": "该 client_request_id 已处理过，未重复更新掌握度"
  },
  "trace_id": "a1b2c3"
}
```

**错误**：
- `QUESTION_NOT_FOUND`（404）`{question_id}` — 题目不存在
- `QUESTION_NO_KP`（400）`{question_id}` — 题目无知识点标签
- `BAD_REQUEST`（400）`{question_id | ts}` — 题目 kp 无法解析，或 `ts` 越界（now-30天 ~ now+1分钟）
- `422`（`code=40001`）— `score` 越界、`source` 非法枚举、必填字段缺失；`data.errors` 为 Pydantic 字段级报错

**逻辑**：幂等检查 → 查题 → 权重三级兼容（手动等权 → 题库权重 → 等权兜底）→ before → `process_answer`（7步流水线）→ 写 practice_event → after → 组装 delta。`is_wrong` 不传则按 `score<0.5` 兜底。

### 5.5 POST /students/{id}/recommendations — 粗召回

**body**：
```json
{ "kp_ids": ["J03", "J04"] }
```

**成功响应（200）**
```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "student_id": 1001,
    "groups": [
      {
        "kp_id": "J03",
        "kp_name": "一元二次方程",
        "m": 0.6234,
        "has_data": true,
        "direction": "巩固",
        "question_count": 2,
        "questions": [
          { "question_id": "Q-2024-001", "ques_type": "选择题", "difficulty": "适中", "d": 0.55, "p": 0.5821, "kp_ids": ["J03"] },
          { "question_id": "Q-2024-012", "ques_type": "选择题", "difficulty": "较难", "d": 0.7, "p": 0.4533, "kp_ids": ["J03"] }
        ]
      }
    ],
    "empty_kps": [
      { "kp_id": "J04", "kp_name": "二次函数", "reason": "题库中该知识点无 p∈[0.3,0.8] 的题" }
    ]
  },
  "trace_id": "a1b2c3"
}
```

**错误**：
- `KP_NOT_FOUND`（404）`{invalid_kp_ids:[...]}`
- `422`（`code=40001`）— `kp_ids` 为空列表或缺失（违反 `min_length=1`）；`data.errors` 为 Pydantic 字段级报错

**逻辑**：IRT `p=g+(1-g)·σ(K·(m-d))`，保留 `p∈[0.30,0.80]`（ZPD），按 p 降序。不去重、不排除已做题（归排序层）。`direction`=掌握度方向（未接触/补弱/巩固/变式/进阶），`empty_kps` 列出无候选的 KP。

|------|------|------|
| `scope_type` | module / kp_ids | 必填，范围类型 |

## 六、错误码表

| 码 | 常量 | HTTP | 含义 | 使用处 |
|----|------|------|------|--------|
| 0 | OK | 200/201 | 成功 | 所有成功响应 |
| 40001 | BAD_REQUEST | 400 / 422 | 参数错误 | 400：submit-answer(kp/ts越界)、learning-status(aspects非法)；422：Pydantic 请求体校验失败（`data.errors`） |
| 40002 | QUESTION_NO_KP | 400 | 题目无知识点 | submit-answer |
| 40400 | NOT_FOUND | 404 | 路由/资源不存在 | HTTPException 404（路由不匹配） |
| 40401 | SCOPE_NOT_FOUND | 404 | 范围无效 | learning-status |
| 40403 | KP_NOT_FOUND | 404 | kp_id 不存在 | mastery / practice-events / recommendations |
| 40404 | QUESTION_NOT_FOUND | 404 | 题目不存在 | submit-answer |
| 40501 | METHOD_NOT_ALLOWED | 405 | 方法不允许 | HTTPException 405（如对 GET 接口用 DELETE） |
| 50001 | INTERNAL | 500 | 内部错误 | 兜底 handler |

**预留**：`UNAUTHORIZED(40101)` / `FORBIDDEN(40301)` / `RATE_LIMITED(42901)` 已接入 HTTPException 映射（401/403/429 → 对应码），将来上鉴权/限流即自动生效；`STUDENT_NOT_FOUND(40402)` 仍预留。
