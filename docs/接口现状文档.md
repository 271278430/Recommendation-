## 一、服务概览

| 项 | 值 |
|----|-----|
| 框架 | FastAPI + Uvicorn |
| 入口 | `python -m service.main`（监听 `:8800`） |
| 接口前缀 | `/api/v1` |
| 风格 | **REST**（资源名词复数 + HTTP 方法表动作 + 嵌套子资源） |
| 数据层 | `mastery_store`（PostgreSQL）+ 题库 JSONL + kg_graph 静态文件 |

启动顺序：`lifespan`（建 KPRegistry）→ TraceId 中间件 → 异常处理器 → 路由。

---

## 二、分层架构

```
api/   （路由层·薄）  参数校验 → 调 svc → 组装 ApiResponse
 ↑
svc/   （业务层）     业务逻辑，错误时直接 raise BizError
 ↑
core/  （基础设施）   response / config / deps / kp_registry / middleware / logging
 ↑
mastery_store（数据层）掌握度模型 + practice_event 读写 + 常量
```

依赖方向：`api → svc → core → mastery_store → data/`，严禁反向。`api/` 不含业务逻辑，`svc/` 错误直接 `raise BizError`。

## 三、统一约定

### 3.1 响应封装
所有业务接口统一返回 `ApiResponse`：`{code, msg, data, trace_id}`，响应头带 `X-Trace-Id`。`code=0` 成功。例外：`GET /health` 裸返回 `{"status":"ok"}`。

### 3.2 错误处理
svc 层发现错误 → `raise BizError(code, msg, http_status, data)` → 全局 handler 转 ApiResponse。api 层不做错误翻译。

### 3.3 REST 约定（核心）
- **资源用名词复数**：`students`、`practice-events`、`recommendations`
- **HTTP 方法表动作**：`GET`=读（幂等无副作用）、`POST`=创建/计算
- **路径表达层级**：`/students/{student_id}/mastery` = "该学生的掌握度"
- **参数位置**：
  - 路径参数 `{student_id}` 表资源标识
  - GET 的过滤条件走 **query**（`?kp_ids=J03&kp_ids=J04`）
  - POST 的数据走 **body**（student_id 在路径，不重复放 body）
- **状态码**：POST 创建资源返回 **201**（如 `/practice-events`），其余成功 200

### 3.4 KP 标识
API 边界一律用 `kp_id`（题库唯一 id）；内部 `kp_idx` 不外露；转换走 `KPRegistry`。全量查询只返回有题库映射的 idx。

### 3.5 时间
内部统一 naive UTC；submit-answer 的 `ts` 按 ISO 8601 解析，范围限制 now-30天~now+1分钟。

## 五、接口详解

### 5.1 GET /students/{id}/mastery — 遗忘后掌握度
**query**：`kp_ids`（可选，list，不传=全部）
**错误**：`KP_NOT_FOUND` (404) `{invalid_kp_ids:[...]}`
**逻辑**：只读衰减（不落库），数学与 mastery_store 写路径逐行一致。冷启动返回 `m=0.5, has_data=false`。

### 5.2 POST /students/{id}/mastery — 初始化/重置掌握度（201）
**body**：`{correct_counts?, wrong_counts?, last_ts?}`，值均为 `{kp_id: int|ISO8601}`；三字段全空 = 冷启动
**错误**：`KP_NOT_FOUND` (404) `{invalid_kp_ids:[...]}`；count 为负 / `last_ts` 非 ISO8601 → Pydantic validator 返回 422
**逻辑**：kp_id 校验 → 组装 α/β/last_ts 向量（长度 N_KP，未提及填 0/None）→ 调 `mastery_store.init_student`（`source='init'`，`log_events=False`，UPSERT 覆盖）→ 回读返回（与 GET 同格式）。注入公式 `m=(correct+P)/(correct+P+wrong+P)`。已有数据会被覆盖，故同时支持初始化与重置。

### 5.3 GET /students/{id}/practice-events — 做题序列
**query**：`kp_id`(必填)、`limit`(1..500, 默认50)、`wrong_only`(默认false)
**错误**：`KP_NOT_FOUND` (404) `{invalid_kp_ids:[...]}`
**逻辑**：按时间倒序，kp_id 校验在 api 层。

### 5.4 POST /students/{id}/practice-events — 答题（201）
**body**：`{question_id, score[0..1], is_wrong?, source(exam/homework/classwork), ts?, equal_weights?, client_request_id?}`
**错误**：`QUESTION_NOT_FOUND`(404) / `QUESTION_NO_KP`(400) / `BAD_REQUEST`(400, kp无法解析或 ts 越界)
**逻辑**：幂等检查 → 查题 → 权重三级兼容 → before → `process_answer`（7步流水线）→ 写 practice_event → after → 组装 delta。幂等命中返回 `{idempotent_replay:true}`。

### 5.5 POST /students/{id}/recommendations — 粗召回
**body**：`{kp_ids: list[str] min_length=1}`
**错误**：`KP_NOT_FOUND` (404) `{invalid_kp_ids:[...]}`
**逻辑**：IRT `p=g+(1-g)·σ(K·(m-d))`，保留 `p∈[0.30,0.80]`（ZPD），按 p 降序。不去重、不排除已做题（去重归排序层）。

### 5.6 GET /students/{id}/learning-status — 学情
**query**：`scope_type`(module/kp_ids)、`scope_value`(list；module 传1个模块名，kp_ids 传知识点id)、`aspects`(⊆{mastery,history})、`history_days`、`history_limit`、`mastery_detail`、`include_graph`、`edge_types`、`cooc_min_weight`
**错误**：`SCOPE_NOT_FOUND`(404, 范围无效) / `BAD_REQUEST`(400, aspects 非法)
**逻辑**：`resolve_scope` → mastery 部分（衰减掌握度+统计）→ history 部分（事件）→ 可选 graph 边。

### 5.7 GET 元数据接口
| 路径 | 响应 data |
|------|----------|
| `/api/v1/students` | `[student_id, ...]` |
| `/api/v1/knowledge-points` | `[{kp_id, kp_name, module}, ...]` |
| `/api/v1/knowledge-graph/edges` | `[{from, to, type, subtype?, weight?}, ...]` |

均走 ApiResponse 封装 + trace_id。

## 六、错误码表

| 码 | 常量 | HTTP | 含义 | 使用处 |
|----|------|------|------|--------|
| 0 | OK | 200/201 | 成功 | 所有成功响应 |
| 40001 | BAD_REQUEST | 400 | 参数错误 | submit-answer(kp/ts越界)、learning-status(aspects非法) |
| 40002 | QUESTION_NO_KP | 400 | 题目无知识点 | submit-answer |
| 40401 | SCOPE_NOT_FOUND | 404 | 范围无效 | learning-status |
| 40403 | KP_NOT_FOUND | 404 | kp_id 不存在 | mastery / practice-events / recommendations |
| 40404 | QUESTION_NOT_FOUND | 404 | 题目不存在 | submit-answer |
| 50001 | INTERNAL | 500 | 内部错误 | 兜底 handler |

**预留未用**：`UNAUTHORIZED(40101)` / `FORBIDDEN(40301)` / `STUDENT_NOT_FOUND(40402)` / `RATE_LIMITED(42901)`（将来鉴权/限流用）。

## 七、数据依赖

| 依赖 | 位置 | 用途 |
|------|------|------|
| PostgreSQL | `mastery_store/.env` | student_mastery / practice_event 表 |
| 题库 | `data/初中_九年级.jsonl` | 题目属性 + 倒排索引（懒加载） |
| kp_id 映射缓存 | `data/kg_graph/kp_id_map.json` | kp_id→kp_name |
| 知识图谱 | `data/kg_graph/{nodes,prereq_edges,cooc_adj}.*` | 模块→KP、先修/共现边 |
| 题目权重 | `data/question_kp_weights.jsonl` | 一题多 KP 的权重 |

**核心常量**：IRT `K=5.0`（svc/recommend.py、svc/practice.py）、ZPD `[0.30,0.80]`、npmi_min `0.25`。
