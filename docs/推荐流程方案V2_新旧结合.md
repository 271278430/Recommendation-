# 推荐流程方案 V2（新旧结合 · 漏斗架构）

> 本方案把"老方案（KP + 难度召回）"与"新方案（锚点 + 以题推题）"整合为**漏斗**：通道 A 召回出"难度合格"的候选池，通道 B 在池内按学生做题序列做"关系精选"。
>
> 一切建立在《学情建模与学情状态更新机制建模V1.md》之上：`m`、`m_peak`、`last_ts`、`N`、IRT 预测正确率 `p` 均来自该机制。
>
> 题目标签参考《题目标签说明》，区分 V1（结构/解法标签缺失）与 V2（标签补齐）两期。

---

## 0. 核心设计原则

1. **漏斗，不是双通道并行**。通道 A 按 p 约束召回出候选池（保难度）；通道 B 在该池内按做题序列精选（保关系）。两阶段正交。
2. **候选池即合法宇宙**。一道好推荐必须"难度合适 + 关系合适"。难度合适是硬门槛，所以通道 A 的 p 池就是通道 B 的唯一素材——**通道 B 不可能选出难度错的题**，因此不再需要下游 p 过滤器。
3. **以题推题是"池内选择"，不是独立召回**。通道 B 不扫题库，只对通道 A 已生成的小池子做关系打分。
4. **状态是上游，方向驱动一切**。6 个学习状态先定，映射到 6 个推题方向，每个方向决定目标 p、锚点来源、精选关系类型。
5. **标签分阶段**。V1 无结构/解法标签 → 通道 B 用粗规则（kgPoints/题型/难度）；V2 标签补齐 → 用《题目标签说明》第 3 节精规则。
6. **可解释输出**。每道推荐题带"方向 + 理由 + 锚点（可空）+ 与锚点关系（可空）"。

## 1. 数据依赖

### 1.1 学生侧

| 数据 | 来源 | 用途 |
|------|------|------|
| `m`（虚拟衰减后） | 机制 `α/(α+β)`，读时套机制 2.2 节衰减 | 状态分类、p 计算 |
| `m_peak`（虚拟衰减后） | 机制，τ_peak=180 衰减 | 遗忘判定 |
| `last_ts` | 机制 | 未接触/遗忘判定 |
| `Δt` | 派生：`now − last_ts`（天），NULL 时不存在 | 遗忘判定 |
| `gap` | 派生：`m_peak − m` | 遗忘判定、复习池排序 |
| `N = α+β` | 机制 | 置信度（影响排序，见 §8.3） |
| `practice_log` | 练习记录库 | **重建做题序列**、锚点、趋势 |
| `seen_questions` | 练习记录库 | 去重（已做题） |

**做题序列重建**（通道 B 的输入）：

```
某 KP 的做题序列 = practice_log 中 kg_ids 含该 KP 的记录，按 last_ts 升序
                = [(题, last_score, last_wrong_ts, 时间), ...]
```

### 1.2 题目侧（题库已有字段）

| 字段 | 用途 |
|------|------|
| `kgPoints` `[{name,id}]` | KP 匹配、单/多标签、综合度 |
| `quesType` | 题型、选择题归类、g 推导、变式判定 |
| `difficulty`（五档文字） | 经 `DIFF_MAP` 映射为 `d` |
| `subjectAbilities` | 能力维度（V2 变式/进阶辅助） |

### 1.3 IRT 常量（必须与掌握度标定同源）

```
DIFF_MAP = {容易:0.15, 较易:0.35, 适中:0.55, 较难:0.75, 困难:0.90}   # 与 web_app.DIFF_MAP 一致
_G_MAP   = {单选题:0.25, 多选题:0.10, 判断题:0.50, 其余:0.0}
k        = 5        # 全局区分度，与 m 标定一致；题库无逐题 k
p = g + (1-g) · σ(k·(m-d))        # σ 为 sigmoid
```

### 1.4 图谱侧

| 数据 | 文件 | 使用约束 |
|------|------|------|
| 先修关系 | `data/kg_graph/prereq_edges.json` | **仅在目标集合 T 内**查询，禁止越界全局遍历 |
| 共现关系 | `data/kg_graph/cooc_adj.npy` | 同上，仅判多标签题是否有机综合 |

### 1.5 V2 待补标签

V1 题库 `attrs=[]`，以下标签缺失，需 `augment_tags.py` 扩展（当前只补知识点）：

- 结构层：核心对象、核心条件、问题目标、表征形式
- 解法层：解题方法、关键步骤（有序序列）
- 难度细化层：条件复杂度、表征转换、推理分支（推理步数由关键步骤派生）

**补齐前通道 B 用 §6.3 V1 粗规则；补齐后用 §6.3 V2 精规则。**

## 2. 总体流程（漏斗，7 步）

```
Step 1  选目标知识点（KP）                      ← 指定范围 / 全局模式（方向池选 KP）
Step 2  状态分类（6 态）→ 推题方向（6 方向）      ← 上游
Step 3  通道 A：p 约束召回 → 该 KP 候选池          ← 唯一召回，保难度
Step 4  通道 B：做题序列 → 锚点+趋势 → 池内精选    ← 条件跑，保关系
          探索/复习 不跑；精选空则退回池子直接用
Step 5  子图过滤（目标集合 T 内）
Step 6  排序（关系分 + p_closeness + 题型 + 难度）
Step 7  重排（去重 / 比例控制 / 进阶外来 KP 限额 / 截断）
Step 8  输出（题 + 方向 + 理由 + 锚点 + 关系）
```

---

## 3. Step 1：选目标知识点

**指定范围模式**：老师/系统选定 KP 集合 `T`。

**全局模式**：不指定范围时，按**方向池**选 KP（修正 V1 仅按 m 最低选、漏掉遗忘 KP）。KP 选择与 §9.2 题配额**解耦**——这里只保证每方向池非空，最终题比例由 Step 7 控制。

```
全局模式选 KP（每方向池上限 M_KP_POOL = 8，可配置）：
  探索池：last_ts == NULL 的 KP，任取 ≤8
  补弱池：m < 0.45，按 m 升序取前 ≤8
  巩固池：0.45 ≤ m < 0.65，按 m 升序取前 ≤8
  变式池：0.65 ≤ m < 0.80，按 m 降序取前 ≤8
  进阶池：m ≥ 0.80，按 m 降序取前 ≤8
  复习池：满足遗忘判定（§4）的 KP，按 gap 降序取前 ≤8
  合并六池为 T（上限 48 个 KP）。
```

---

## 4. Step 2：状态分类 → 推题方向

### 4.1 六态决策树（虚拟衰减后变量，首次命中即停）

```
Step 0: IF last_ts == NULL                                        → 探索（未接触）
Step 1: IF m_peak ≥ 0.70 AND m < m_peak - 0.15 AND Δt > 21天      → 复习（遗忘）
Step 2: IF m < 0.45                                               → 补弱（基础薄弱）
Step 3: IF m < 0.65                                               → 巩固（当前不稳）
Step 4: IF m < 0.80                                               → 变式（变式不稳）
Step 5: ELSE                                                      → 进阶（可提升）
```

### 4.2 方向主表

目标 p 用**单边/宽区间**（双边窄区间在离散难度档下会饥饿）。`target_mid` 为该方向期望 p 中心，用于 §8 的 `p_closeness` 与兜底。

| 方向 | 状态 | 目标 p（单边） | target_mid | 通道 A | 通道 B | 锚点源 | 精选关系 | 配额 |
|------|------|:--:|:--:|:--:|:--:|------|:--:|:--:|
| 探索 | 未接触 | 0.50 ≤ p ≤ 0.70 | 0.60 | ✅ | ❌ | — | — | 5% |
| 补弱 | 基础薄弱 | p ≥ 0.70 | 0.80 | ✅ | 有锚点跑 | 序列最近错题 | 同类 | 35% |
| 巩固 | 当前不稳 | p ≥ 0.65 | 0.75 | ✅ | 有锚点跑 | 序列最近错题 | 同类 | 25% |
| 变式 | 变式不稳 | 0.45 ≤ p ≤ 0.70 | 0.60 | ✅ | 有锚点跑 | 序列最近做对题 | 变式 | 15% |
| 进阶 | 可提升 | 0.40 ≤ p ≤ 0.65 | 0.55 | ✅ | 有锚点跑 | 序列最近做对题 | 进阶 | 10% |
| 复习 | 遗忘 | p ≥ 0.75 | 0.85 | ✅ | ❌ | — | — | 10% |

> - **目标 p 含义**：补弱/复习要高成功率（建信心、激活 savings），只设下限；变式/进阶要挑战，设上下限；探索取中等带定位。
> - **通道 B 只在补弱/巩固/变式/进阶 跑**，且需序列有可用锚点；探索/复习 不跑，候选池直接进排序。

---

## 5. Step 3：通道 A —— p 约束召回候选池（唯一召回）

对 `T` 中每个 KP，召回**含该 KP 标签**且 **p 满足该方向目标 p 约束**的题，作为该 KP 的**候选池**。

> **候选以三元组 `(题, 目标KP, 方向, p)` 为单位**：一道多知识点题可被多个 KP 召回，各自带自己的 p（用触发召回的目标 KP 的 m 计算）。去重见 §9.1。
>
> **实现注记**：用 KP→题倒排索引（项目已有 `web_app.kp_questions`），勿全库扫描。

```
对每个目标 KP（掌握度 m，方向 d，查 §4.2 得目标 p 约束与 target_mid）：
  对该 KP 倒排索引里每道题：
    p = g + (1-g)·σ(5·(m - DIFF_MAP[difficulty]))
    若 p 满足方向 d 的目标 p 约束 → 加入该 KP 候选池，记录 (题, 该KP, 方向d, p)
  若该 KP 候选池为空：
    兜底：取 p 最接近 target_mid 的题；仍空则标记该 KP "无合适题目"，前端弹窗
```

> 候选池是通道 B 的唯一素材。池内所有题已 p 合格，**不需要下游 p 过滤器**。

---

## 6. Step 4：通道 B —— 做题序列 → 池内精选（条件跑）

### 6.1 激活条件（全部满足才跑）

```
条件 1：方向 ∈ {补弱, 巩固, 变式, 进阶}（探索/复习 不跑）
条件 2：该 KP 候选池非空
条件 3：该 KP 做题序列存在可用锚点（见 6.2）
```

不满足时：候选池原样进 §5 子图过滤，输出用"无锚点"理由模板。

### 6.2 序列重建与锚点选择

```
序列 = practice_log 中 kg_ids 含该 KP 的记录，按 last_ts 升序
锚点（按方向取）：
  补弱 / 巩固 → 序列中 last_wrong_ts 最近的题（错题锚点）
  变式 / 进阶 → 序列中 last_score ≥ 0.5 且最近的题（做对题锚点）
锚点失效阈值：锚点 last_ts 距今 > 2 × 该 KP 的遗忘常数 τ 即视为失效
  （τ 由该 KP 的 firm 推导，∈[7,90] 天，与机制联动：学得扎实的 KP 锚点保留更久）
  失效 → 无锚点 → 通道 B 不跑，候选池原样进 §5
```

> 序列的核心用途是**选锚点**（以题推题的结构参照）。趋势微调对结果影响微弱且增加复杂度，不纳入核心流程，留作 V2 增强。

### 6.3 关系判定规则

> **关系判定只看结构，不看难度。** 难度完全由通道 A 的 p 池保证（§5）；通道 B 在已 p 合格的池内只判"候选与锚点的结构关系"。锚点的绝对难度不影响判定——同类/变式/进阶是结构关系，不是难度关系。

**V1 粗规则（无结构/解法标签，仅用 kgPoints / quesType）**：

| 关系 | 判定（候选 vs 锚点） |
|------|------|
| 同类 | kgPoints 相同 + quesType 相同 |
| 变式 | kgPoints 相同 + quesType 不同 |
| 进阶 | 候选题 kgPoints 严格包含锚点 kgPoints（综合度更高） |

**V2 精规则（标签补齐后，按《题目标签说明》第 3 节）**：

| 关系 | 相同（必须） | 变化 |
|------|------|------|
| 同类 | 核心知识点、核心结构、解题方法、关键步骤 | 仅数值/变量名/人名/情境/非核心文字 |
| 变式 | 核心知识点、核心能力、核心目标（或等价）、核心方法 | 至少一维变化：核心条件 / 表征 / 条件-目标方向 / 局部步骤 / 情境 |
| 进阶 | 保留核心知识点、核心结构、核心步骤 | 增加：知识点 / 条件 / 目标 / 步骤 / 表征转换 / 分类讨论 |

### 6.4 池内精选

```
对每个激活的 (KP, 方向)：
  取锚点题（6.2）
  对该 KP 候选池每道题，按 §6.3 判定与锚点的关系
  精选出关系 == 该方向"精选关系"（§4.2）的题：
    补弱/巩固 → 同类
    变式 → 变式
    进阶 → 进阶
  每道精选题打标签：来源锚点 ID、关系类型、rel_score=1
  精选结果作为该 KP 的最终候选（替代原池子）
```

### 6.5 兜底

```
若精选后为空（池内无符合关系的题）：
  退回该 KP 候选池原样使用，rel_score=0.5，输出用"无锚点"理由（关系标签为空）
```

## 7. Step 5：子图过滤（目标集合 T 内）

| 方向 | 过滤规则 |
|------|------|
| 探索 | 仅留单标签题（kgPoints 在 T 内个数 = 1） |
| 补弱 | 仅留单标签题 且 不含 T 外 KP |
| 巩固 | 仅留不含 T 外 KP 的题 |
| 变式 | 仅留不含 T 外 KP 的题 |
| 进阶 | 保留全部，但含 T 外 KP 的题限额 ≤ 该方向配额 20%（§9.4 执行） |
| 复习 | 仅留单标签题 且 不含 T 外 KP |

---

## 8. Step 6：排序

### 8.1 候选题特征（均在 T 内计算）

| 特征 | 含义 | 计算 |
|------|------|------|
| `form_score` | 选择题在前 | quesType ∈ {单选题,多选题} → 1，否则 0 |
| `rel_score` | 关系精准度 | 通道 B 精选且关系匹配 → 1；退回池子/通道 A → 0.5 |
| `p_closeness` | p 贴近 target_mid | `1 - \|p - target_mid\| / 0.20`，clamp [0,1] |
| `is_single_kp` | 单标签 | kgPoints 在 T 内个数 = 1 → 1 |
| `kp_count` | T 内标签数 | kgPoints 在 T 内个数 |
| `has_variant` | 含变式特征 | quesType=综合题 或 kp_count>1 或 subjectAbilities 含{应用意识,模型思想,创新意识} |
| `has_graph_edge` | 有机综合 | T 内任意两个 KP 间存在先修/共现边 |
| `is_outside_kp` | 含 T 外 KP | kgPoints 存在不属于 T 的知识点 → 1 |

### 8.2 各方向排序键

```
所有方向首键：form_score DESC        # 选择题在前

探索：  form_score, is_single_kp DESC, difficulty ASC
补弱：  form_score, rel_score DESC, is_single_kp DESC, difficulty ASC
巩固：  form_score, rel_score DESC, is_single_kp DESC, difficulty ASC
变式：  form_score, rel_score DESC, has_variant DESC, difficulty ASC
进阶：  form_score, rel_score DESC, kp_count DESC, has_graph_edge DESC, is_outside_kp ASC, difficulty DESC
复习：  form_score, is_single_kp DESC, difficulty ASC
```

末键 difficulty：探索/补弱/巩固/变式/复习 ASC（易→难），进阶 DESC（同综合度偏难）。

> 末键 `difficulty` 只控制**展示顺序**，不影响题是否入选——入选资格已由通道 A 的 p 池保证（§5）。难度与关系判定完全分离。

### 8.3 置信度 N 的影响

```
低置信度（N < 8）：排序在末键前插入 p_closeness DESC（优先定位准确的题）
高置信度（N ≥ 8）：正常按 §8.2
```

## 9. Step 7：重排

### 9.1 三元组去重 + 已做题去重

- **三元组去重**：同一题 ID 可能被多个目标 KP 召回（多个三元组），保留**关系最强**的那一个（进阶 > 变式 > 同类 > 无关系）；关系同级时再按 p 贴近 target_mid 取胜者。避免一道多知识点题对某 KP 是"变式"、对另一 KP 是"同类"时丢失更强的关系价值。
- **已做题去重**：查 `seen_questions`，剔除学生做过的题（含锚点题本身，不重复推荐）。

### 9.2 比例控制

推荐题总数上限 `TOP_N` 默认 20。配额 = `floor(TOP_N × 占比)`，余数按"补弱→巩固→变式→进阶→复习→探索"补。某方向召回不足时，多余配额按同顺序转让。

| 方向 | 配额 |
|------|:--:|
| 补弱 | 35% |
| 巩固 | 25% |
| 变式 | 15% |
| 进阶 | 10% |
| 复习 | 10% |
| 探索 | 5% |

### 9.3 KP 多样性约束（同方向 KP 轮转）

同方向内每个 KP 最多贡献 `KP_CAP` 道（默认 3，可配置），防止某方向推荐题全来自一个 KP。在 §8 排序后的有序列表上按序取题：某 KP 达到 `KP_CAP` 后跳过其后续题，让位给该方向其他 KP；被跳过的题在该方向配额未满时可回填，否则丢弃。

### 9.4 进阶外来 KP 限额

进阶方向取题后，若含 T 外 KP 的题超过该方向配额 20%，截断到 20%，空位用进阶内部题回填；内部不足则按 §9.2 转让。

### 9.5 截断

各方向按 §8 排序、过 §9.3（KP 轮转）和 §9.4（进阶外来限额）后取前配额道，按方向优先级（补弱→巩固→变式→进阶→复习→探索）拼接，总长 ≤ TOP_N。

---

## 10. Step 8：输出

```json
{
  "question_id": "...",
  "direction": "补弱|巩固|变式|进阶|复习|探索",
  "reason": "...",
  "anchor_question_id": "可空",
  "relation_to_anchor": "同类|变式|进阶|可空"
}
```

**理由模板**：

- 有锚点（通道 B 精选）：
  - 补弱/巩固："你最近在《锚点题》上做错，这道题和它同类，适合补弱/巩固。"
  - 变式："你在该知识点已掌握，这道题和《锚点题》考同一核心，但换了问法/条件，用来迁移训练。"
  - 进阶："你在该知识点已掌握，这道题在《锚点题》基础上增加了知识点/步骤，用来综合提升。"
- 无锚点（通道 A 池子直接用，或探索/复习）：
  - 探索："你未接触过该知识点，推荐中等难度题进行初始定位。"
  - 补弱/巩固："你该知识点掌握度偏低/不稳，推荐基础/巩固题。"
  - 复习："你曾较好掌握该知识点但近期未练，推荐少量复习题确认。"

## 13. 逻辑问题自评

> 本架构自查出的逻辑薄弱点。已解决的列前，仍开放的列后。

### 已解决

- ~~变式/进阶锚点与候选池难度错位~~ → **澄清为非问题**：难度只在通道 A（m-d/p）管一次，候选池生成后即 p 合格；通道 B 用做题序列在池内选题**只看结构关系、不看难度**（§6.3 已把难度从关系判定剥离）。锚点难度不影响同类/变式/进阶判定。
- ~~跨 KP 聚合缺 KP 多样性~~ → **已修**：§9.3 KP 轮转约束（同方向每 KP ≤ `KP_CAP` 道，默认 3）。
- ~~趋势微调效果弱~~ → **已决**：移除趋势微调（§6.2）。序列只用于选锚点，不引入对结果影响微弱的趋势项；趋势留作 V2 增强。
- ~~三元组去重丢跨 KP 关系~~ → **已修**：§9.1 去重改为保留"关系最强"的三元组（进阶>变式>同类），同级再比 p 贴近度。
- ~~锚点失效阈值拍脑袋~~ → **已修**：锚点失效阈值 = 2 × 该 KP 的 τ（与机制遗忘常数联动）。

### 仍开放 / 固有限制

1. **精选空 → 退回池子，可解释性降级**。通道 B 池内精选为空时退回原池（rel_score=0.5，无关系标签）。某方向大量 KP 精选空时该方向退化为纯通道 A。候选池规模（受目标 p 单边化影响）直接决定精选成功率。
   **处置**：上线后监控精选空率；必要时放宽 §6.3 关系判定（如"同类"允许 quesType 同族，单选↔多选）。
2. **低 N / 新 KP 序列短**。新 KP 做题序列短、锚点未必有 → 通道 B 不跑 → 退化为纯通道 A。冷启动降级，属合理降级。
3. **V1 粗规则同类判定过粗**。"同类 = kgPoints+题型全同"会把同知识点同题型但结构不同的题判为同类，精选可能挑到实质不同的题。依赖 V2 结构标签解决。

## 16. 端到端示例（验证流程自洽）

**输入**：学生小张，目标集合 T = {勾股定理}（指定范围模式）。

**Step 1–2**：查掌握度（虚拟衰减后）`m=0.55, m_peak=0.62, last_ts=3天前`。
- 决策树：last_ts 非 NULL；不满足遗忘（m_peak<0.70）；0.45≤m<0.65 → **巩固**。
- 查 §4.2：目标 p ≥ 0.65，target_mid=0.75，通道 B 锚点源=序列最近错题，精选关系=同类。

**Step 3 通道 A**：在"勾股定理"倒排索引里，对小张 m=0.55 算每题 p：
- 题C（单选，较易 d=0.35）：p = 0.25+0.75·σ(5·(0.55−0.35)) = 0.80 ✓
- 题D（填空，较易 d=0.35）：p = 0+1·σ(5·0.20) = 0.73 ✓
- 题E（单选，适中 d=0.55）：p = 0.25+0.75·σ(5·0) = 0.625 ✗（< 0.65）
- 候选池 = {题C(p=0.80), 题D(p=0.73)}

**Step 4 通道 B**：重建做题序列 = [题X(填空, 错, 10天前), 题Y(单选, 对, 5天前)]。
- 锚点 = 序列最近错题 = **题X（填空）**，距今 10 天 < 2τ（未失效）。
- 池内精选关系=同类（§6.3：kgPoints 同 + quesType 同）：
  - 题C（单选）vs 锚点题X（填空）：quesType 不同 → 非同类
  - 题D（填空）vs 锚点题X（填空）：kgPoints 同 + quesType 同 → **同类** ✓
- 精选结果 = {题D}，打标签 rel_score=1，anchor=题X，relation=同类。

**Step 5 子图过滤**：巩固 → 仅留不含 T 外 KP。题D 单标签勾股定理，保留。

**Step 6 排序**（巩固键：form_score, rel_score, is_single_kp, difficulty ASC）：
- 题D：form_score=0(填空), rel_score=1, is_single_kp=1 → 排序元组 (0,1,1,较易)

**Step 7 重排**：去重（题D 未做过）、配额（巩固 25%×20=5 道，本例只 1 道）、KP 轮转（单 KP 不触发）。

**Step 8 输出**：
```json
{
  "question_id": "题D",
  "direction": "巩固",
  "reason": "你最近在《题X》上做错，这道题和它同类（同为填空、考勾股定理），适合巩固。",
  "anchor_question_id": "题X",
  "relation_to_anchor": "同类"
}
```

> 此例验证：难度由通道 A 的 p 锁定（题E 因 p<0.65 出局），关系由通道 B 在池内判定（题D 因与锚点同类入选），两者分离、各司其职。
