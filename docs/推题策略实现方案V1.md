前置说明，数据依赖与标签体系

本文档中引用的题目侧字段，来源于题库 `data/初中_九年级.jsonl`。以下字段已在题库中存在，可直接使用：

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `kgPoints` | `[{name, id}]` | 题目考察的知识点列表 | `[{"name":"勾股定理","id":"J030004000200080003"}]` |
| `difficulty` | 枚举 | 题目难度（五档文字） | `容易` / `较易` / `适中` / `较难` / `困难` |
| `quesType` | 枚举 | 题型 | `单选题` / `多选题` / `填空题` / `简答题` / `综合题` / `计算题` / `作图题` / `证明题` / `解方程` / `问答题` / `阅读理解` |
| `subjectAbilities` | 枚举（逗号分隔） | 学科能力标签 | `运算能力` / `几何直观` / `推理能力` 等，共 13 种 |

**难度数值映射**：`difficulty` 为文字枚举，需映射为 `[0, 1]` 数值后参与 IRT 预测答对率 `p` 计算（`p = g + (1-g)·σ(k·(m-d))`，ZPD 区间 `p∈[0.30, 0.80]`）：

| 文字值 | 数值 `d` |
|--------|:--:|
| 容易 | 0.1 |
| 较易 | 0.25 |
| 适中 | 0.5 |
| 较难 | 0.75 |
| 困难 | 0.9 |

**考察形式归类**：排序中区分选择题/非选择题，按 `quesType` 归类：

| 类别 | `quesType` |
|------|------|
| 选择题 | `单选题`、`多选题` |
| 非选择题 | 其余全部 |

| `has_graph_edge`（有机综合） | 步骤四 可提升 排序 | 题目的 `kgPoints` 在目标集合内，且任意两个 KP 间存在先修边或共现边 |

**练习记录库**（步骤四排序依赖的数据组件）：

掌握度更新机制（见《学情建模与学情状态更新机制建模V1.md》）只持久化聚合后的 `α, β, m_peak, last_ts`，不保留每次练习的题目结构信息。排序中的"与错题同题型""见题型多样性"需要依赖每次练习的结构信息，因此需要独立的练习记录库。该库在掌握度更新流水线的步骤 7（持久化）阶段并行写入，与掌握度状态互不依赖。

练习记录库由两张表组成：

| 表 | 用途 | TTL |
|----|------|:--:|
| `seen_questions` | 去重（判断学生是否做过某题） | 长期保留 |
| `practice_log` | 排序查询（按 KP/题型/难度/时间维度查询练习记录） | 30 天窗口 |

**`seen_questions` 表结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `student_id` | str | 分区键 |
| `question_id` | str | 题目 ID |
| `first_seen_ts` | int | 首次遇见该题的时间戳 |

**`practice_log` 表结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `student_id` | str | 分区键 |
| `question_id` | str | 题目 ID |
| `kg_ids` | `[str]` | 题目携带的知识点 ID 列表（保留多对多关系） |
| `kp_count` | int | `len(kg_ids)`，区分单标签/多标签题 |
| `ques_type` | str | 题型 |
| `difficulty` | str | 难度等级（五档文字） |
| `last_score` | float | 最近一次得分率 `y ∈ [0,1]` |
| `total_attempts` | int | 累计做了几次 |
| `wrong_count` | int | 累计错了几次 |
| `first_ts` | int | 首次做题时间戳 |
| `last_ts` | int | 最近一次做题时间戳（对/错都更新） |
| `last_wrong_ts` | int | 最近一次做错的时间戳（仅答错时更新） |

> `last_wrong_ts` 不被答对覆盖。场景：学生 1 月 1 日做错，1 月 5 日做对，`last_ts=1月5日`，`last_wrong_ts` 保持为 `1月1日`。查询"最近 30 天做错的题型"时用 `last_wrong_ts` 而非 `last_ts` 作为时间窗口条件。

**写入逻辑**（每次练习事件完成后执行）：

```
IF question_id 在 practice_log 中存在:
    UPDATE practice_log:
        total_attempts += 1
        IF y < 0.5:
            wrong_count += 1
            last_wrong_ts = now
        last_score = y
        last_ts = now
ELSE:
    INSERT INTO seen_questions: {student_id, question_id, first_seen_ts=now}
    INSERT INTO practice_log: {全部字段，首次写入}
```

**TTL 清理策略：**

```sql
-- 30 天内未碰过 且 从没错过的记录：删除
DELETE FROM practice_log 
WHERE last_ts < now - 30d AND wrong_count == 0;

-- 做错过的记录即使超过 30 天也保留（顽固错题有长期参考价值）
-- 可设上限：每学生最多保留 200 条 practice_log 记录
```

**排序依赖的查询接口：**

```sql
-- Q1 去重: 学生是否做过某题
SELECT 1 FROM seen_questions WHERE student_id = ? AND question_id = ?

-- Q2 当前不稳: 最近30天该KP下做错的题型分布
SELECT ques_type, COUNT(*) AS cnt
FROM practice_log
WHERE student_id = ? 
  AND ? IN kg_ids          -- 判断该KP是否在题目的kg_ids列表中
  AND last_wrong_ts > now - 30d
GROUP BY ques_type
ORDER BY cnt DESC

-- Q3 变式不稳: 该KP下已见过的所有题型
SELECT DISTINCT ques_type
FROM practice_log
WHERE student_id = ? AND ? IN kg_ids

-- Q4 基础薄弱: 前置KP中最近30天错题最多的KP
SELECT kg_id, COUNT(*) AS wrong_cnt
FROM practice_log
WHERE student_id = ? 
  AND kg_ids INTERSECT ?   -- ?为前置KP ID列表
  AND last_wrong_ts > now - 30d
GROUP BY kg_id
ORDER BY wrong_cnt DESC
```

步骤一，筛选需要推荐的目标知识点
用户自定义的选择需要推题的知识点范围，比如上完一堂课，老师选择该堂课涉及到的知识点为每一个学生个性化的推题。
构成学生学情子图，用于后面的子图排序，图实体是知识点，图关系包含先修，共现关系。
【注意】如果不定义范围，则系统会给每一个学生该整个知识框架中的所有知识点推题，是全局性的，这个时候推荐出来的题目量会更大，掌握度高知识点和掌握度低的知识点都推题，所以如果是全局的推题，应该要先筛选掌握度最低的 n 个知识点（n 可配置，默认 10），仅对这 n 个知识点执行后续步骤。
步骤二，从题库中召回与该学生对应知识点难度匹配的题目

对每一位学生，根据步骤一筛选出来的知识点列表，去题库中寻找含该知识点标签的题目，记该学生该知识点的掌握度是 `m`，含该知识点标签的题目难度为 `d`。筛选条件：

```
|m - d| ≤ 0.15
```

把符合该范围内的题召回。

若某个知识点召回题目数为 0（题库中该知识点下没有难度落在 `[m-0.15, m+0.15]` 区间的题目），则该知识点不参与后续步骤，并在返回结果中标记为"无合适题目"，由前端弹窗告知用户"知识点 XXX 暂无适合的推荐题目"。
步骤三，为该学生每一个知识点分配状态策略

3.1 状态分类输入变量

以下变量取自掌握度建模与更新机制（见《学情建模与学情状态更新机制建模V1.md》），在推题时对知识点执行读时虚拟衰减（衰减公式见机制 2.2 节）后取最新值：

| 变量 | 含义 | 来源 |
|------|------|------|
| `m` | 当前掌握度 | `α / (α + β)`，虚拟衰减后 |
| `m_peak` | 历史峰值掌握度 | 持久化在库，经过虚拟衰减（τ_peak=180天） |
| `last_ts` | 上次练习时间戳 | 持久化在库，NULL 表示从未练习 |
| `Δt` | 距上次练习天数 | `now - last_ts`，`last_ts=NULL` 则 `Δt` 不存在 |

3.2 分类决策流程

六种状态按优先级从上到下判断，首次命中即停止：

```
输入（虚拟衰减后）：m, m_peak, last_ts

Step 0: IF last_ts == NULL
        → 【未接触】

Step 1: IF m_peak ≥ 0.70
           AND m < m_peak - 0.15
           AND Δt > 21 天
        → 【遗忘】

Step 2: IF m < 0.45
        → 【基础薄弱】

Step 3: IF m < 0.65
        → 【当前不稳】

Step 4: IF m < 0.80
        → 【变式不稳】

Step 5: ELSE
        → 【可提升】
```

3.3 各状态详细策略

3.3.1 未接触

| 维度 | 内容 |
|------|------|
| 判据 | `last_ts == NULL` |
| 学生画像 | 该知识点从未被练习过，系统无任何证据积累 |
| 推题方向 | **初始探索** |
| 状态推题策略 | - 按教学进度或老师指定的知识点范围推题；<br>- 难度以适中为主（初始 mastery=0.5，IRT 算出 p 后召回 `p∈[0.30, 0.80]` 的题）；<br>- 题目结构覆盖该知识点的核心题型 |
| 题目子图推题策略 | - 匹配知识点节点直接召回；<br>- 如有前置知识点且也无练习记录，可少量混入前置知识点基础题；<br>- 使用结构标签覆盖核心结构 |
| 推荐理由 | 学生未接触过该知识点，系统以中等难度题目进行初始定位，快速建立掌握度基线 |
| 建议推题量 | 3-5 道 |

3.3.2 基础薄弱

| 维度 | 内容 |
|------|------|
| 判据 | `m < 0.45`，且不满足遗忘条件 |
| 学生画像 | - 从未真正掌握过该知识点（m_peak < 0.70），或 m_peak 虽高但下跌主因是失败累积而非遗忘；<br>- 错误证据明显，简单题或基础题也出现错误；<br>- 前置知识点往往也存在薄弱 |
| 推题方向 | **前置补洞** |
| 状态推题策略 | - 优先选择当前知识点或前置知识点相关题目；<br>- 难度以容易、较易为主；<br>- 题目结构应偏基础，例如定义理解、基础判断、直接计算、图象识别；<br>- 不优先推荐综合题、压轴题或大跨度变式题 |
| 题目子图推题策略 | - 匹配知识点节点，确认是否命中当前薄弱点；<br>- 如有知识图谱前置关系，优先召回前置知识点题目；<br>- 使用难度属性过滤高难题；<br>- 使用结构标签筛选基础结构题 |
| 推荐理由 | 该知识点当前掌握度较低且非因遗忘，系统判断需要从头建构基础，因此推荐低难度、直接命中知识点的基础题 |
| 建议推题量 | 5-8 道 |

3.3.3 当前不稳

| 维度 | 内容 |
|------|------|
| 判据 | `0.45 ≤ m < 0.65`，且不满足遗忘条件 |
| 学生画像 | - 当前掌握度处于中等水平；<br>- 有一定正确证据，但也存在错误证据；<br>- 同一知识点下表现有对有错；<br>- 系统判断学生尚未稳定掌握 |
| 推题方向 | **当前巩固** |
| 状态推题策略 | - 优先选择当前知识点相关题目；<br>- 难度以较易、适中为主；<br>- 题目结构与学生已错题或当前学习内容相近；<br>- 题型变化不宜过大；<br>- 变式程度控制在低到中等 |
| 题目子图推题策略 | - 使用知识点节点进行直接匹配；<br>- 使用题目结构标签匹配相近结构；<br>- 使用难度属性控制题目不过难；<br>- 使用题型属性保持练习稳定性 |
| 推荐理由 | 学生在该知识点上已有部分正确证据，但掌握还不稳定，因此推荐同知识点、相近结构的题目进行巩固 |
| 建议推题量 | 4-6 道 |

3.3.4 变式不稳

| 维度 | 内容 |
|------|------|
| 判据 | `0.65 ≤ m < 0.80`，且不满足遗忘条件 |
| 学生画像 | - 学生对该知识点已有一定掌握；<br>- 基础题或同结构题可以完成；<br>- 但换题型、换问法、换参数或换情境后容易出错；<br>- 或在较复杂结构下表现低于预期 |
| 推题方向 | **变式训练** |
| 状态推题策略 | - 知识点仍然围绕当前知识点；<br>- 难度不宜过低，一般为较易或适中；<br>- 题目结构、问法、参数、情境或题型应有变化；<br>- 避免跨度过大，防止从变式变成综合拔高 |
| 题目子图推题策略 | - 知识点节点保持一致或高度相关；<br>- 使用变式标签筛选换问法、换参数、换题型、换情境题；<br>- 使用结构标签判断是否与原题结构不同；<br>- 使用方法标签控制解题方法是否保持一致或轻微变化 |
| 推荐理由 | 学生对该知识点已有一定掌握，但在不同题型或问法下仍可能不稳定，因此推荐同知识点的变式题进行迁移训练 |
| 建议推题量 | 3-5 道 |

3.3.5 可提升

| 维度 | 内容 |
|------|------|
| 判据 | `m ≥ 0.80`，且不满足遗忘条件 |
| 学生画像 | - 当前掌握度较高；<br>- 证据量和置信度相对稳定（N 较大）；<br>- 近期没有明显低于预期表现；<br>- 当前知识点已不属于主要薄弱点 |
| 推题方向 | **综合提升** |
| 状态推题策略 | - 题目可以包含当前知识点及其关联知识点；<br>- 难度以适中、较难为主；<br>- 优先选择多知识点、多步骤、综合应用题；<br>- 可选择函数与几何综合、实际应用、面积最值、压轴结构等题目；<br>- 控制跨度，避免超过学生当前能力过多 |
| 题目子图推题策略 | - 匹配当前知识点及关联知识点；<br>- 使用知识点数量判断综合程度；<br>- 使用结构标签筛选综合应用或压轴结构；<br>- 使用能力标签判断是否涉及建模、推理、综合应用能力 |
| 推荐理由 | 学生已基本掌握当前知识点，系统推荐包含关联知识点的综合题，帮助其从单点掌握过渡到综合应用 |
| 建议推题量 | 3-5 道 |

3.3.6 遗忘

| 维度 | 内容 |
|------|------|
| 判据 | `m_peak ≥ 0.70` ∧ `m < m_peak - 0.15` ∧ `Δt > 21 天` |
| 学生画像 | - 历史上曾稳定掌握该知识点（m_peak ≥ 0.70）；<br>- 当前掌握度因久未练习而显著回落（gap > 0.15）；<br>- 下跌主要由时间衰减造成（Δt > 21 天），而非答题失败累积；<br>- 借助 savings 机制可在少量练习后快速恢复 |
| 推题方向 | **间隔复习** |
| 状态推题策略 | - 推荐少量题，不占用过多推荐位；<br>- 难度以中等为主（匹配当前衰减后的 m 水平）；<br>- 先推 1-2 道基础确认题，答对后 savings 快速拉升 m，后续可跟进提升题；<br>- 若确认题答错，转为按基础薄弱策略处理 |
| 题目子图推题策略 | - 匹配久未练习知识点；<br>- 使用难度属性控制风险（d 匹配当前 m 而非历史峰值）；<br>- 使用结构标签覆盖核心题型；<br>- 可搭配少量变式题确认是否真正恢复 |
| 推荐理由 | 学生曾经较好掌握该知识点，但近期较久未练导致 mastery 回落，借助 savings 机制推荐少量复习题即可快速激活，无需大量补洞 |
| 建议推题量 | 1-2 道 |

3.4 状态与 IRT 预测答对率对照

推题步骤二中 IRT 预测答对率 `p∈[0.30, 0.80]` 的筛选区间，在各状态下对题目难度分布的影响（k=5，非选择题 g=0）：

| 状态 | 典型 m 区间 | p 筛选区间 | 命中难度档 | 与策略一致性 |
|------|:--:|:--:|------|:--:|
| 未接触 | 0.50 | p∈[0.30, 0.80] | 容易+较易+适中 | ✅ 中等难度起步，初始定位 |
| 基础薄弱 | 0.02~0.44 | p∈[0.30, 0.80] | 容易+较易 | ✅ 匹配基础建构需求 |
| 当前不稳 | 0.45~0.64 | p∈[0.30, 0.80] | 容易+较易+适中 | ✅ 匹配巩固需求 |
| 变式不稳 | 0.65~0.79 | p∈[0.30, 0.80] | 适中+较难+困难 | ✅ 匹配变式训练（有挑战但不过难） |
| 可提升 | 0.80~1.0 | p∈[0.30, 0.80] | 适中+较难+困难 | ✅ 匹配综合提升需求 |
| 遗忘 | 0.45~0.64 | p∈[0.30, 0.80] | 容易+较易+适中 | ✅ 匹配复习唤醒（题比历史水平简单，savings 会拉升 m） |

步骤四，排序

排序采用多关键字分层排序，而非加权公式。每个状态定义自己的排序键序列，排序键之间是严格的优先级关系（前一个键相等时才看后一个键），不存在"因素 A 分高可以弥补因素 B 分低"的情况。

4.1 题目结构特征（排序键的数据来源）

以下特征在排序时对每道召回题目计算，所有计算均在步骤一的目标知识点集合范围内进行，不访问范围外的图谱节点：

| 特征 | 含义 | 计算方法 |
|------|------|------|
| `form_score` | 考察形式 | `quesType ∈ {单选题, 多选题}` → 1（选择题），否则 → 0（非选择题） |
| `is_single_kp` | 是否单标签题 | 题目的 `kgPoints` 在目标集合内的个数 = 1 → 1，> 1 → 0 |
| `kp_count` | 目标集合内标签数 | 题目的 `kgPoints` 中属于目标集合的个数 |
| `is_prereq` | 是否命中前置 KP | 题目的 `kgPoints` 在目标集合内，且该 KP 是当前目标 KP 的先修前置 → 1，否则 → 0。（仅当题目和目标 KP 都在目标集合内时判断先修关系） |
| `has_graph_edge` | 多标签间是否有图边 | 题目的 `kgPoints`（目标集合内的部分）中，任意两个 KP 之间存在先修边或共现边 → 1，否则 → 0 |
| `is_outside_kp` | 是否含范围外 KP | 题目的 `kgPoints` 中存在不在目标集合内的知识点 → 1，否则 → 0 |
| `wrong_type_match` | 是否匹配错题题型 | 题目的 `quesType` 等于该学生该 KP 最近 30 天做错的任一题型 → 1，否则 → 0。（数据来源：练习记录库 Q2 查询） |
| `is_new_type` | 是否新题型 | 题目的 `quesType` 不在该学生该 KP 已见过的题型集合中 → 1，否则 → 0。（数据来源：练习记录库 Q3 查询） |

4.2 通用过滤规则

排序前，先按状态过滤不适合的题目：

| 状态 | 过滤规则 | 理由 |
|------|------|------|
| 未接触 | 仅保留 `is_single_kp == 1` 的题目 | 学生未接触该 KP，多标签题引入干扰 |
| 基础薄弱 | 仅保留 `is_single_kp == 1` 且 `is_outside_kp == 0` 的题目 | 薄弱学生需要聚焦单一 KP 打基础 |
| 遗忘 | 仅保留 `is_single_kp == 1` 且 `is_outside_kp == 0` 的题目 | 复习确认阶段不能引入干扰 |
| 当前不稳 | 仅保留 `is_outside_kp == 0` 的题目 | 巩固阶段需聚焦目标集合内 |
| 变式不稳 | 仅保留 `is_outside_kp == 0` 的题目 | 变式训练围绕目标 KP，不跨域 |
| 可提升 | 保留全部，但标记 `is_outside_kp == 1` 的题目限额 ≤ 该状态配额的 20% | 少量跨域综合题帮助连接知识体系 |

4.3 各状态排序键序列

```
未接触：
  ORDER BY is_single_kp DESC,     -- 单标签在前
           difficulty ASC          -- 难度升序

基础薄弱：
  ORDER BY is_prereq DESC,         -- 目标KP的前置KP题目排前面（先修地基）
           is_single_kp DESC,      -- 单标签在前（过滤后全部是单标签，此键冗余但保留）
           difficulty ASC          -- 难度升序

当前不稳：
  ORDER BY wrong_type_match DESC,  -- 与错题相同题型的排前面（针对性巩固）
           is_single_kp DESC,      -- 多标签中单标签优先（聚焦）
           difficulty ASC          -- 难度升序

变式不稳：
  ORDER BY is_new_type DESC,       -- 未见过的新题型排前面（变式多样性）
           difficulty ASC          -- 难度升序

可提升：
  ORDER BY kp_count DESC,          -- 多标签综合题排前面
           has_graph_edge DESC,    -- 有机综合（有图边）优先于标签堆砌
           is_outside_kp ASC,      -- 范围外KP题目排后面（点缀性质）
           difficulty DESC         -- 同综合度偏难优先

遗忘：
  ORDER BY is_single_kp DESC,      -- 单标签确认题在前
           difficulty ASC          -- 难度升序
```

4.4 输出

每个知识点按上述排序键序列对其召回题目排序，输出该知识点的有序题目列表。各知识点的列表独立排序后，按状态分组合并为六个有序队列，交由步骤五做去重、比例控制和最终截断。

步骤五，重排过滤

在步骤四输出的题目序列上执行以下操作：

5.1 去重

两道去重：

- **题库去重**：同一道题可能被多个知识点召回，只保留第一次出现的位置，后续重复出现时剔除。
- **已做题去重**：查询 `seen_questions` 表，剔除学生已经做过的题目。

5.2 比例控制

六种状态的知识点推荐题目数量服从可配置比例。默认比例如下：

| 状态 | 默认配额占比 | 说明 |
|------|:--:|------|
| 基础薄弱 | 35% | 优先级最高，占比最大 |
| 当前不稳 | 25% | 需要巩固，占比次之 |
| 变式不稳 | 15% | 变式训练 |
| 可提升 | 10% | 综合提升 |
| 遗忘 | 10% | 间隔复习 |
| 未接触 | 5% | 初始探索 |

全局返回题目总数上限记为 `N_max`（默认 20 道，可配置），按上述比例分配各状态配额（向下取整，余数优先分配给基础薄弱）。每个状态内按步骤四的排序取前配额道题目。若某状态实际召回数不足配额，多余配额按上述优先级顺序（基础薄弱 → 当前不稳 → 变式不稳 → 可提升 → 遗忘 → 未接触）依次转让。

5.3 最终截断

按比例分配后，将各状态的题目按状态优先级顺序拼接成最终推荐列表，返回给前端。列表长度 ≤ N_max。
