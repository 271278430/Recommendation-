# 数据库表设计文档

> 学情系统所有数据存在同一个 PostgreSQL 库（`mastery`）。共 **3 张表**：
> - `student_mastery` —— 掌握度**当前状态**（聚合，每学生一行）
> - `mastery_event` —— 掌握度**变更日志**（m 怎么变的）
> - `practice_event` —— **做题历史**（每次答题一行）
>
> 三者关系：一次答题 → 更新 `student_mastery`（聚合当前态）+ 记 `mastery_event`（掌握度变化）+ 记 `practice_event`（做了哪道题、对错）。

---

## 概览

| 表 | 粒度 | 行数 | 一句话 | 谁写 | 谁读 |
|---|---|---:|---|---|---|
| `student_mastery` | 一学生一行 | 691 | 各知识点的掌握度当前值（α,β,m_peak,last_ts 数组） | `process_answer`（答题）/ `init_student`（初始化） | 遗忘/推题/图谱接口 |
| `mastery_event` | 一次掌握度变化一行 | 49 | 掌握度变化前后及差值（回溯/分析用） | `update`（m 变化时） | 分析/审计 |
| `practice_event` | 一次答题一行 | 13800 | 学生做了哪道题、得分、对错、知识点（做题序列） | `log_practice_event`（答题记录） | 学情历史/错题本/以题推题 |

> 建表脚本：`mastery_store/init/01_mastery.sql`（前两张）、`02_practice_event.sql`（第三张）。容器启动自动执行。

## 1. `student_mastery` —— 掌握度当前状态

**用途**：存每个学生在 612 个知识点上的掌握度参数（Beta 分布 α,β + 峰值 + 上次练习时间）。一学生一行，掌握度用定长数组存。

| 列 | 类型 | 可空 | 说明 |
|---|---|:--:|---|
| `student_id` | BIGINT | NOT NULL | 学生 ID（**主键**） |
| `alpha` | REAL[612] | NOT NULL | 有效正确证据，初始 2.0(=P)，下标 1..612 = 知识点 0..611 |
| `beta` | REAL[612] | NOT NULL | 有效错误证据，初始 2.0(=P) |
| `m_peak` | REAL[612] | NOT NULL | 历史峰值掌握度，初始 0.5（重学节省用） |
| `last_ts` | TIMESTAMPTZ[612] | NULL | 各知识点上次练习时间，初始 NULL（遗忘衰减用） |
| `updated_at` | TIMESTAMPTZ | NOT NULL | 行最后更新时间，默认 now() |

**数组下标约定（重要）**：`alpha/beta/m_peak/last_ts` 都是长度 612 的数组，**下标 1..612 对应知识点 0..611**（即 `alpha[k+1]` 是知识点 k 的值）。知识点名→索引见 `mastery_store.NAME2IDX`。

**索引**：`student_mastery_pkey`（student_id 主键）。数组列内部不带索引（按学生取整行后在内存里按 idx 访问）。

**读写**：
- 写：`process_answer` / `update`（答题时，套事务 + advisory lock 按 student_id 串行化）；`init_student`（初始化/重置，UPSERT 覆盖，**不写** mastery_event）
- 读：`get_state` / `get_mastery`（遗忘接口、推题、图谱都读它）

## 2. `mastery_event` —— 掌握度变更日志

**用途**：记录掌握度 m 每次变化的前后值与差值，用于回溯"掌握度是怎么变成现在这样的"。**可选表**（不影响主流程，仅分析/审计）。

| 列 | 类型 | 可空 | 说明 |
|---|---|:--:|---|
| `id` | BIGSERIAL | NOT NULL | 自增主键 |
| `student_id` | BIGINT | NOT NULL | 学生 ID |
| `kp_idx` | INTEGER | NOT NULL | 数组下标（1..612，= 知识点 idx + 1；CHECK 约束 `BETWEEN 1 AND 612`） |
| `old_m` | REAL | NULL | 变化前掌握度 |
| `new_m` | REAL | NULL | 变化后掌握度 |
| `delta` | REAL | NULL | 差值（new_m - old_m） |
| `source` | TEXT | NULL | 来源：exam / homework / classwork |
| `task_id` | TEXT | NULL | 任务 ID |
| `created_at` | TIMESTAMPTZ | NOT NULL | 事件时间，默认 now() |

**索引**：`idx_event_student_time`（student_id, created_at DESC）、`idx_event_kp`（kp_idx）。

**读写**：`update` 在 m 变化时自动写入（`|delta|>1e-6` 才记）。读用于分析/画掌握度变化曲线。`prune_events(days)` 可定期清理。

## 3. `practice_event` —— 做题历史

**用途**：记录学生每次答题（做了哪道题、得分、对错、考了哪些知识点）。一次答题一行。是学情历史、错题本、以题推题、推荐去重的数据源。

| 列 | 类型 | 可空 | 说明 |
|---|---|:--:|---|
| `id` | BIGSERIAL | NOT NULL | 自增主键 |
| `student_id` | BIGINT | NOT NULL | 学生 ID |
| `question_id` | TEXT | NOT NULL | 题目标识（来源+题号，如 `exam_20251016_3`） |
| `kp_ids` | TEXT[] | NOT NULL | 该题考察的知识点 kp_id 列表（一题可多个） |
| `client_request_id` | TEXT | NULL | 幂等键（可选）；传入则按 (student_id, client_request_id) 去重 |
| `ques_type` | TEXT | NULL | 题型：单选题/填空题/... |
| `difficulty` | TEXT | NULL | 难度档：容易/较易/适中/较难/困难（有则填） |
| `d` | NUMERIC(4,2) | NULL | DIFF_MAP 映射后的难度数值（有则填） |
| `score` | NUMERIC(5,3) | NOT NULL | 得分率 ∈ [0,1] |
| `is_wrong` | BOOLEAN | NOT NULL | 是否判错（score < 0.5） |
| `source` | TEXT | NULL | 来源：exam / homework / classwork |
| `ts` | TIMESTAMPTZ | NOT NULL | 答题时间 |

**索引**（4 个）：
- `pe_student_ts` (student_id, ts DESC) —— 查某学生时间线
- `pe_kp_gin` GIN(kp_ids) —— **按知识点查序列**（`WHERE kp = ANY(kp_ids)`）
- `pe_student_q` (student_id, question_id) —— 按题查 / 去重
- `pe_client_req` UNIQUE (student_id, client_request_id) WHERE client_request_id IS NOT NULL —— **幂等防重**（同键只写一次）

**关键设计**：
- `kp_ids` 存**知识点 kp_id**（与题库/接口统一标识一致），一本 One KP Registry 转换。多知识点题只存**一行**（`kp_ids` 装多个），查任一知识点都能命中。

**读写**：
- 写：`log_practice_event(...)`（答题时调，紧跟 `process_answer` 之后）
- 读：`get_kp_sequence`(按知识点) / `get_student_events`(按学生) / `seen_question_ids`(去重)

---

## 三表关系（一次答题的数据流）

```
学生答一道题
     │
     ├─ process_answer ──→ 更新 student_mastery（α,β,m_peak,last_ts 聚合当前态）
     │                  └─ 记 mastery_event（m 从 old 变 new 的差值）
     │
     └─ log_practice_event ──→ 插 practice_event（做了哪题、得分、对错、知识点）
```

| 问题 | 看哪张表 |
|---|---|
| 学生现在各知识点掌握度多少？ | `student_mastery` |
| 学生的掌握度是怎么变化到现在的？ | `mastery_event` |
| 学生做过哪些题、对错、某知识点的做题序列？ | `practice_event` |
