# 推荐服务接口设计文档 V1

> 本文档是推荐服务的**落地实现参考**，供模型/工程师照此实现。
>
> 流程基于三步：① 选目标知识点 → ② 按掌握度定推荐方向 → ③ 按 IRT 预测答对率 `p∈[0.30, 0.80]` 召回难度适宜的题目（ZPD_Questions）。
>
> 难度匹配**采用 `p` 模式**（IRT 预测答对率 `p∈[0.30, 0.80]`，考虑题型猜测率 g 和区分度 k）。学情数据（`m`、`m_peak`、`last_ts`、`N`）来自《学情建模与学情状态更新机制建模V1.md》的掌握度存储，**读取时先经遗忘机制做虚拟衰减**。

---

## 0. 服务定位

| 项 | 说明 |
|----|------|
| 服务名 | 个性化推题服务（Recommendation Service） |
| 输入 | 学生 ID + 推题范围（章/节/专题 或 指定知识点） |
| 输出 | 按知识点 × 方向分组的 ZPD 候选题目列表 |
| 依赖 | 学生学情掌握度、题库、知识点图谱 |
| 协议 | HTTP/JSON（UTF-8） |

> 本服务只到**召回**：返回每个目标知识点的 ZPD 候选库（符合难度 + 符合 KP 的全集）。**最终推题数量/比例/去重/排序是下游选编阶段，不在本服务范围。**

---

## 1. 通用约定

### 1.1 请求规范
- `Content-Type: application/json; charset=utf-8`
- 鉴权：`Authorization: Bearer <token>`；token 解出 `student_id`（学生视角）或 `teacher_id`（教师视角）
- 所有数值字段用浮点/整型，不传字符串数字
- 时间戳统一 ISO 8601（UTC）

### 1.2 响应规范
统一外层包裹：

```json
{
  "code": 0,
  "msg": "ok",
  "data": { ... },
  "trace_id": "req-xxxxxx"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | int | 0=成功；非 0 见 §7 错误码 |
| `msg` | string | 人类可读信息 |
| `data` | object/array/null | 业务数据，失败时为 null |
| `trace_id` | string | 链路追踪 ID |

## 2. 数据模型

### 2.1 KnowledgePoint（知识点）

```json
{
  "kp_id": "J030004000200080003",
  "kp_name": "勾股定理",
  "chapter": "四边形",
  "section": "勾股定理",
  "topic": ""
}
```

### 2.2 MasteryStatus（掌握状态，读时虚拟衰减后）

```json
{
  "kp_id": "J030004000200080003",
  "m": 0.55,
  "m_peak": 0.62,
  "last_ts": "2026-07-11T10:00:00Z",
  "N": 12,
  "has_data": true
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `m` | float[0,1] | 当前掌握度（虚拟衰减后） |
| `m_peak` | float | 历史峰值（虚拟衰减后） |
| `last_ts` | string/null | 上次练习时间；null=从未练习 |
| `N` | int | 证据量 α+β |
| `has_data` | bool | 是否有练习记录（last_ts≠null 且 N>2P） |

### 2.3 Direction（推荐方向）

枚举值：

| 方向 | 判定（按 `m`） | 含义 |
|------|------|------|
| `补弱` | `m < 0.45` | 基础薄弱 |
| `巩固` | `0.45 ≤ m < 0.65` | 当前不稳 |
| `变式` | `0.65 ≤ m < 0.80` | 变式不稳 |
| `进阶` | `m ≥ 0.80` | 可提升 |

> 未练习知识点（`has_data=false`）`m` 取先验 0.5 → 落入 `巩固`，巩固的同时可进行摸底测试。

### 2.4 Question / ZPDQuestion（题目）

```json
{
  "question_id": "64a1...",
  "stem_preview": "在Rt△ABC中，∠C=90°，...",
  "kg_points": [{"kp_id":"J030004000200080003","kp_name":"勾股定理"}],
  "ques_type": "单选题",
  "difficulty": "较易",
  "d": 0.35,
  "m_d": 0.20,
  "in_zpd": true
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `d` | float | 难度数值（`DIFF_MAP[difficulty]`） |
| `m_d` | float | `\|m-d\|` |
| `in_zpd` | bool | 是否落在 ZPD（IRT 预测答对率 `p∈[0.30, 0.80]`） |

### 2.5 难度映射常量（须与掌握度标定同源）

```
DIFF_MAP = {容易:0.15, 较易:0.35, 适中:0.55, 较难:0.75, 困难:0.90}
```

## 3. 接口概览

| # | 接口 | 方法 | 路径 | 对应步骤 |
|---|------|:--:|------|:--:|
| 1 | 选定目标知识点 | POST | `/api/recommend/target-kps` | Step 1 |
| 2 | 确定推荐方向 | POST | `/api/recommend/directions` | Step 2 |
| 3 | 召回 ZPD 题目 | POST | `/api/recommend/questions` | Step 3 |

> 复合"一键推题"接口暂不实现；由调用方按 Step 1 → Step 2 → Step 3 顺序串联调用。

---

## 4. 接口详解

### 4.1 【Step 1】选定目标知识点

`POST /api/recommend/target-kps`

**功能**：按范围（章/节/专题）或教师指定的知识点列表，确定本次推题的目标知识点集合。可返回每个 KP 的掌握度预览，供教师勾选。

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `student_id` | string | 是 | 学生 ID |
| `scope_type` | enum | 二选一 | 范围类型：`chapter`/`section`/`topic`/`custom` |
| `scope_id` | string | 条件必填 | `scope_type≠custom` 时填，章/节/专题 ID |
| `kp_ids` | string[] | 条件必填 | `scope_type=custom` 时填，教师指定的知识点 ID 列表 |
| `include_mastery` | bool | 否 | 是否返回掌握度预览，默认 `true` |

**响应 `data`**：

```json
{
  "student_id": "S1001",
  "scope": {"type":"section","id":"sec_pythagorean"},
  "target_kps": [
    {
      "kp_id": "J030004000200080003",
      "kp_name": "勾股定理",
      "mastery": {"m":0.55,"m_peak":0.62,"last_ts":"2026-07-11T10:00:00Z","N":12,"has_data":true}
    }
  ],
  "count": 1
}
```

**示例**：

```bash
curl -X POST https://api.example.com/api/recommend/target-kps \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"student_id":"S1001","scope_type":"section","scope_id":"sec_pythagorean"}'
```

**错误**：`scope_id` 不存在 → `40401`；学生不存在 → `40402`。

---

### 4.2 【Step 2】确定推荐方向

`POST /api/recommend/directions`

**功能**：对给定知识点，读取（虚拟衰减后）掌握度 `m`，按 §2.3 阈值判定推荐方向。

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `student_id` | string | 是 | 学生 ID |
| `kp_ids` | string[] | 是 | 需判定方向的知识点 ID 列表 |

**响应 `data`**：

```json
{
  "student_id": "S1001",
  "directions": [
    {
      "kp_id": "J030004000200080003",
      "m": 0.55,
      "direction": "巩固",
      "threshold": "0.45 <= m < 0.65",
      "has_data": true,
      "reason": "掌握度0.55，处于巩固区间，推荐同知识点相近结构题巩固"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `direction` | enum | `补弱`/`巩固`/`变式`/`进阶` |
| `threshold` | string | 命中的阈值条件（可读） |
| `reason` | string | 方向判定理由（可直显前端） |

**示例**：

```bash
curl -X POST https://api.example.com/api/recommend/directions \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"student_id":"S1001","kp_ids":["J030004000200080003"]}'
```

**错误**：`kp_ids` 为空 → `40001`；某 kp_id 不存在 → `40403`（`data.invalid_kps` 返回无效列表）。

---

### 4.3 【Step 3】召回 ZPD 题目

`POST /api/recommend/questions`

**功能**：对每个目标知识点，去题库召回含该知识点标签、且 IRT 预测答对率 `p∈[0.30, 0.80]` 的题，即 ZPD_Questions。**返回完整候选库，不做数量截断**（最终选编是下游阶段）。

**请求体**：

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|:--:|:--:|------|
| `student_id` | string | 是 | - | 学生 ID |
| `kp_ids` | string[] | 是 | - | 目标知识点列表 |
| `exclude_seen` | bool | 否 | `true` | 是否排除已做题（查 `seen_questions`） |
| `ques_types` | string[] | 否 | `[]`(全部) | 题型过滤，如 `["单选题","填空题"]` |

**响应 `data`**：

```json
{
  "student_id": "S1001",
  "groups": [
    {
      "kp_id": "J030004000200080003",
      "kp_name": "勾股定理",
      "m": 0.55,
      "direction": "巩固",
      "questions": [
        {
          "question_id": "64a1...",
          "stem_preview": "在Rt△ABC中，∠C=90°，AC=3，BC=4，求AB。",
          "kg_points": [{"kp_id":"J030004000200080003","kp_name":"勾股定理"}],
          "ques_type": "单选题",
          "difficulty": "较易",
          "d": 0.35,
          "m_d": 0.20,
          "in_zpd": true
        }
      ],
      "returned": 1
    }
  ],
  "empty_kps": [
    {"kp_id":"J03000500010001","kp_name":"投影","reason":"题库中该知识点无难度匹配题目"}
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `groups` | array | 每个有题的知识点一个分组 |
| `groups[].questions` | array | ZPD 候选题，组内按 `\|m-d\|` 升序，同值选择题在前 |
| `groups[].returned` | int | 该 KP 候选库大小（未截断） |
| `empty_kps` | array | 召回为空的知识点，前端据此弹窗"暂无适合题目" |

**说明**：Step 3 的 `m` 和 `direction` 由服务**内部重新从掌握度存储读取 + 虚拟衰减 + 阈值判定**得到，不依赖 Step 2 的输出（三个接口可独立调用）。

**示例**：

```bash
curl -X POST https://api.example.com/api/recommend/questions \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"student_id":"S1001","kp_ids":["J030004000200080003"]}'
```

**错误**：题库索引未就绪 → `50001`；`kp_ids` 全部无题 → 仍返回 200，`groups=[]`，`empty_kps` 列全。

## 5. 步骤依赖与数据流

### 5.1 步骤间数据流

```
Step 1  输入: student_id + scope
        输出: target_kps[{kp_id, kp_name, mastery?}]          ← mastery 可选预览
                          │ (取 kp_id)
Step 2  输入: student_id + kp_ids
        输出: directions[{kp_id, m, direction, reason}]
                          │ (Step 3 不消费此输出)
Step 3  输入: student_id + kp_ids（来自 Step 1）
        内部: 重新读掌握度存储 → m(虚拟衰减) → 阈值判定 direction
        输出: groups[{kp_id, m, direction, questions[]}]
```

> Step 2 和 Step 3 都**各自独立**从掌握度存储取 `m`（虚拟衰减后）；Step 3 **不依赖** Step 2 的输出。三个接口可单独调用，由调用方按 Step 1 → Step 2 → Step 3 顺序串联。

### 5.2 各步骤功能与依赖

| 步骤 | 功能 | 依赖组件 |
|------|------|------|
| Step 1 | 确定目标 KP 集合 | ①章节→KP 映射（`scope≠custom` 时）②掌握度存储+虚拟衰减（`include_mastery=true` 时） |
| Step 2 | 按 m 判方向 | ①掌握度存储 ②读时虚拟衰减 ③方向阈值规则(0.45/0.65/0.80) |
| Step 3 | 召回 ZPD 候选 | ①掌握度存储+虚拟衰减(取 m) ②方向阈值(算 direction) ③题库倒排索引 KP→题 ④`DIFF_MAP` ⑤`seen_questions`(去重) ⑥题型过滤 |

### 5.3 依赖缺口提示

Step 1 的**章节→KP 映射**组件需确认是否已建好（题库样本 `chapters` 字段为空，可能需从 kp_id 层级编码或独立课程结构表解析）。未就绪时只有 `scope_type=custom` 可用。

---

## 6. 关键参数与默认值

| 参数 | 默认 | 说明 |
|------|:--:|------|
| ZPD 区间 | p ∈ [0.30, 0.80] | IRT 预测答对率范围：低于 0.30 太难（纯挫败），高于 0.80 太简单（无学习价值） |
| `exclude_seen` | `true` | 排除已做题；设 `false` 可用于错题重做/复习 |
| 方向阈值 | 0.45 / 0.65 / 0.80 | 补弱 / 巩固 / 变式 / 进阶 分界 |
| `DIFF_MAP` | 0.15/0.35/0.55/0.75/0.90 | 难度文字→d，**须与掌握度标定同源（不可调）** |

> `DIFF_MAP` 是标定常量，不是可调参数——改它等于重新标定 `m`。

---

## 7. 错误码

| code | HTTP | 含义 | 处理建议 |
|:--:|:--:|------|------|
| 0 | 200 | 成功 | - |
| 40001 | 400 | 参数缺失/非法 | 检查请求体 |
| 40101 | 401 | 未鉴权/token 失效 | 重新登录 |
| 40301 | 403 | 无权访问该学生/范围 | 换 token |
| 40401 | 404 | scope_id 不存在 | 检查范围 ID |
| 40402 | 404 | 学生不存在 | 检查 student_id |
| 40403 | 404 | 部分 kp_id 不存在 | 看 `data.invalid_kps` |
| 40901 | 409 | 掌握度数据未就绪 | 稍后重试 |
| 42901 | 429 | 限流 | 退避重试 |
| 50001 | 500 | 题库索引/内部错误 | 联系运维 |

## 8. 端到端调用示例（教师课后推题）

```bash
# 教师选范围（前端先拉范围树，略）

# 1) 看本节知识点 + 学生掌握度
curl -X POST https://api.example.com/api/recommend/target-kps \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"student_id":"S1001","scope_type":"section","scope_id":"sec_pythagorean"}'

# 2) （可选）单独看方向
curl -X POST https://api.example.com/api/recommend/directions \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"student_id":"S1001","kp_ids":["J030004000200080003"]}'

# 3) 召回候选库
curl -X POST https://api.example.com/api/recommend/questions \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"student_id":"S1001","kp_ids":["J030004000200080003"]}'
```
